# 한계와 향후 과제

- 협력 참여가 전제입니다. 직접 브라우저 호출 차단, actor 인증, 브라우저 읽기 전용 강제, 외부 호출 취소 기능이 아닙니다.
- 하나의 물리적 로컬 DB로 하나의 자원을 관리합니다. 복사본·별도 컨테이너의 같은 경로·NFS·복수 조정기는 지원 모델 밖입니다.
- 안정판 0.3.4에는 daemon, 정확 시각 스케줄러, 자동 메시지, 자동 점유자 문의, timeout 자동 회수가 없습니다. 만료는 실제 호출 종료 증거가 아닙니다. 작업 내용의 진전도 범용 생존 판정이 아닙니다.
- status·탭 기록·저장 스크린샷은 시점별 관측입니다. API의 부분 탭 목록을 전체 인벤토리로 보지 않습니다. 미저장 내용 보존·업로드·공개 발행의 성공을 대신 증명하지 않습니다.
- 소스 배포에는 DB·쿠키·인증정보·세션이 없습니다. 복원 시험은 소프트웨어를 확인하며 실제 서비스 상태나 특정 웹사이트 동작을 보증하지 않습니다.
- 공유 UI의 전역 점유는 보수적 정책입니다. 환경에 따라 독립 탭 DOM/API가 병렬화될 가능성은 있지만 아직 검증하지 않았습니다. 이번 패키지로 운영 전역 점유를 완화하지 않습니다.

## 로드맵이며 현재 기능이 아님

실제 작업자 수명·취소와 연결된 인증된 문의/keepalive, 유한한 timeout 처리, 늦게 돌아온 작업자 차단, 미결 호출의 관찰 전용 복구를 연구합니다. v0.4 후보는 호스트 watchdog 완성본이 아니며 이번 안정 배포에 넣지 않습니다.

탭별 작업과 전역 화면/키보드/마우스/native 파일창/페이지 모달의 독립성은 별도로 검증할 예정입니다. 충돌·중단·재시작 시험 없이 병렬화 기능이나 무충돌 보장을 제시하지 않습니다.
