# 一つの共有リソースを設定する

画面、フォーカス、キーボード、マウス、native ダイアログを共有するブラウザーなど、リソースの境界を決めます。参加ワーカー全員が同じ物理的ローカル SQLite DB を使用する必要があります。別コンテナーの同じパスや DB のコピーは共有を意味しません。稼働前に全ワーカーから読み書きが見えることを確認し、NFS、ネットワークドライブ、クラウド同期フォルダーは使用しません。

次は新規リソースだけの例です。親ディレクトリを先に作ります。ABC_DB は shell 変数であり自動読込されないため、各呼び出しの --db に明示します。

```sh
mkdir -p -m 700 runtime
ABC_DB="$(pwd -P)/runtime/example-ui.db"
agent-browser-coordinator --db "$ABC_DB" init   --args '{"resource":"example-ui","confirmed_idle":true}'
agent-browser-coordinator --db "$ABC_DB" status
```

init は一度だけ実行します。以前のワーカーが今後送信しないことと、すでに送信したすべてのツール呼び出しの終了を外部で確認した場合に限り confirmed_idle=true と宣言できます。プログラム自身が確認する事実ではありません。既存 DB は上書きしません。欠落・破損時は各自で別 DB を作らず、[復旧](RECOVERY.md)を参照してください。

ワーカーごとに固有 actor、新しいコマンドごとに新しい request ID、実呼び出しごとに再利用しない action ID を与えます。actor/tab/checkpoint/evidence は英数字と `_ . : / -` の 1～120 文字です。URL、非公開内容、秘密情報を入れないでください。ラベルは認証ではありません。

priority は 0～100、lease は 10～3600 秒です。安定版コアの連続所有上限は 1800 秒です。他のワーカーが 120 秒以上待機するか、有効優先度が高ければ、次の安全な境界で引き継ぎを要求します。実行中呼び出しを強制キャンセルする制限ではありません。別マシンには別途実装した信頼できる親中継が必要で、このパッケージはリモートサーバーを含みません。

## 0.3.5 のファイル・入力検査

symlink のない物理パスと、グループ/他ユーザーが書き込めない稼働親ディレクトリを使用します。DB は hard link 別名のない通常ファイルである必要があります。既存 dashboard は上書きせず、新しい snapshot 名を指定します。重複 JSON キー、非有限数、未定義の引数を拒否し、読み取りコマンドは引数 payload を受け取りません。これはワーカーの本人認証ではありません。
