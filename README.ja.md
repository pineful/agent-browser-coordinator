# Agent Browser Coordinator

[English](README.md) · [한국어](README.ko.md) · [日本語](README.ja.md)

共有ブラウザー UI を使うエージェントの順番を調整する協調型ツールです。

## なぜ作ったのか

複数のエージェントが同じデスクトップの選択タブ、キーボード、マウス、画面を共有すると、別々のタスクのクリック、入力、ファイル選択ダイアログ、画面観察が干渉することがあります。タブを分けるだけでは共有フォーカスの問題を解決できません。本ツールは共通の所有記録、待機キュー、安全な引き継ぎ、中断後の再開手順を提供します。

現在は共有 UI を一つのリソースとして扱う保守的な方針です。すべてのブラウザー操作の直列化が必要、すべてのタブ単位の DOM/API が競合する、競合を完全に防げる、といった主張はしません。独立したタブ操作の並列化は今後検証する課題であり、今回の機能には含まれません。

## 含まれる機能

**0.3.4** は Python ライブラリーと CLI です。一つのローカル SQLite DB、原子的な所有権、優先度と待ち時間、世代ごとのフェンシングトークン、一意の要求 ID、begin/end、タブ保持記録、検証後の復旧を提供します。外部ランタイム依存はありません。すべてのツールラッパーが手順に参加する必要があり、直接呼び出しを強制的には遮断しません。

ブラウザードライバー、ログイン、サービスアカウント、daemon、自動メッセージ送信、実際の稼働状態は含みません。実験中の v0.4 所有者問い合わせ/keepalive は**この配布には含めず、有効化もしません**。ホストのタスク寿命と timeout の統合検証が必要です。
