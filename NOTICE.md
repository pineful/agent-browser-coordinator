# Source and licensing

This distribution contains a user-developed cooperative coordinator and independently authored public installation/operation documentation. Version 0.3.4 derives from the tested 0.3.3 coordinator and adds the security hardening described in SECURITY_REVIEW.md, plus module and command-line entry points. Tests use synthetic identifiers and temporary databases.

No third-party implementation is vendored. Runtime imports are from the Python standard library. Setuptools is a build dependency, not bundled application code. The MIT notice covers this project's source and documentation; Python and build tools retain their respective licenses. No claim is made about exclusive copyright in machine-generated portions.

The project does not redistribute platform/system instructions, private operator guides, account details, service data, conversation excerpts, browser sessions, live databases, or credentials. Examples must never be treated as authority to access or publish to an external service.
